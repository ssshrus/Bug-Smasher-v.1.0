# 🪳 Bug Smasher

Аркада для Android: дави жуков и тараканов, набирай комбо, открывай уровни.

## Стек
- Kotlin 1.9+
- Jetpack Compose (Material 3)
- Navigation Compose
- Coroutines

## Сборка
```bash
git clone https://github.com/USERNAME/BugSmasher.git
cd BugSmasher
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
